# rustTorrent v0.2.0-beta.5

## Summary

rustTorrent 0.2.0-beta.5 is a feature and hardening build of the daemon, Web
UI, and `rtbit-fluent` desktop client. It expands WebUI API v2 compatibility,
adds torrent and category management controls, improves recheck and recovery
behavior, and hardens state persistence and external URL handling.

This remains beta software. Back up the persistent session directory and the
PostgreSQL database before upgrading, and avoid using it for data that cannot
be downloaded again.

## Highlights

- **WebUI API v2 compatibility.** Web-seed, tracker-tier, downloaded-count,
  app network/shutdown, torrent metadata, and in-flight piece-state endpoints
  are available.
- **Torrent management.** Per-file priorities, category share limits, torrent
  location and rename controls, missing-payload diagnosis, and richer Fluent
  filters and controls are included.
- **Reliability.** Recheck progress, concurrency and throughput limits,
  crash-safe state writes, legacy session migration, low-disk protection,
  retry backoff, and bounded shutdown persistence are improved.
- **Safety and delivery.** External URL fetching is hardened and the release
  workflow smoke-tests fluent desktop artifacts.

## Upgrade notes

- Back up `/home/rtbit/db`, `/home/rtbit/cache` and the credentials directory
  before upgrading.
- No configuration changes are required.
