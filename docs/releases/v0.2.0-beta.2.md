# rustTorrent v0.2.0-beta.2

## Summary

rustTorrent 0.2.0-beta.2 makes it practical to move an existing qBittorrent
library across and to run rustTorrent behind Sonarr and Radarr. It adds a
qBittorrent import tool, closes the remaining gaps the *arr download-client
flow hit in the WebUI API v2 compatibility layer, and makes rechecks on
read-only storage safe.

This remains beta software. Back up the persistent session directory and the
PostgreSQL database before upgrading, and avoid using it for data that cannot
be downloaded again.

## Highlights

- **qBittorrent import tool.** `scripts/import-qbit` reads a qBittorrent
  `BT_backup` directory and adds each torrent to rustTorrent stopped, with the
  same save path, category and tags. It creates missing categories, skips
  torrents rustTorrent already has (so a re-run is safe), and can queue
  throttled rechecks with `--recheck`. The dry run is the default and never
  writes; the tool never opens, moves or writes payload files. See
  `docs/migrating-from-qbit.md`.
- ***arr parity.** The Sonarr/Radarr test-connection and grab sequence now runs
  end to end through the compat layer: `createCategory`, `editCategory` and
  `setCategory` return qBittorrent's 400/409 errors, `torrents/add` honours
  `contentLayout` and the legacy `root_folder`, `torrents/files` reports real
  `piece_range` values, `torrents/info` returns a real `magnet_uri`, and
  `app/preferences` carries `max_inactive_seeding_time`. `setCategory`,
  `files`, `topPrio` and `setForceStart` are now fully compatible.
- **Recheck safety on read-only storage.** With `RTBIT_STORAGE_READ_ONLY`, a
  recheck never truncates, preallocates or creates files. A torrent whose
  payload is missing or short stays stopped and is reported as `missingFiles`
  instead of going live; a complete payload still seeds.

## Upgrade notes

- Back up `/home/rtbit/db`, `/home/rtbit/cache` and the credentials directory
  before upgrading.
- No configuration changes are required. Clients that relied on
  `setCategory` silently accepting an unknown category now get a 409, as they
  do from qBittorrent.
