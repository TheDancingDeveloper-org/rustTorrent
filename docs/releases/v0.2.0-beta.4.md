# rustTorrent v0.2.0-beta.4

## Summary

rustTorrent 0.2.0-beta.4 is a soak build of the daemon, the Web UI and the
native client. The native client is packaged for Linux and Windows, its GUI
moves to fluent2-egui 0.4.2, and the daemon fixes several stop and session
flush races.

This remains beta software. Back up the persistent session directory and the
PostgreSQL database before upgrading, and avoid using it for data that cannot
be downloaded again.

## Highlights

- **Native client packaging.** `rtbit-egui` ships as a `.deb` for Linux and a
  Windows executable. Credentials use the OS keychain on Linux only.
- **Native GUI.** The GUI runs on fluent2-egui 0.4.2 and egui 0.37; popups
  render above modal dialogs.
- **Stop and flush fixes.** Adding a stopped torrent, stopping a torrent that
  is still checking, and the shutdown order of the bitfield flusher and uTP
  dispatcher are corrected. Each session flush writes its own temp file.
- **Tags.** Tags can be renamed, and one tag can be replaced in bulk.

## Upgrade notes

- Back up `/home/rtbit/db`, `/home/rtbit/cache` and the credentials directory
  before upgrading.
- No configuration changes are required.
