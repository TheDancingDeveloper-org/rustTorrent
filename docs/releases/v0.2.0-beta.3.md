# rustTorrent v0.2.0-beta.3

## Summary

rustTorrent 0.2.0-beta.3 is a soak build of the daemon and Web UI. The native
client's file list is a tree, the daemon error bar is the Fluent message bar,
and the status filter is a navigation pane. Error text stays the fixed safe
sentences. The published container image builds without the desktop crates.

This release does not ship Indexarr and does not package the native client.
The downloadable artifacts are the daemon, the Web UI, and the container image.

This remains beta software. Back up the persistent session directory and the
PostgreSQL database before upgrading, and avoid using it for data that cannot
be downloaded again.

## Highlights

- **Native client layout, in the daemon's Web UI path where it applies.** The
  file list is a tree, daemon errors use the Fluent message bar, and the
  status filter is a navigation pane.
- **Container publication.** The server image no longer needs the desktop
  workspace members (`desktop/src-tauri`, `desktop/menu`) in the build
  context. Those crates stay out of the image.

## Upgrade notes

- Back up `/home/rtbit/db`, `/home/rtbit/cache` and the credentials directory
  before upgrading.
- No configuration changes are required.
